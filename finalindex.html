Library Sticker Registration

The Temporary Registration System for Library Stickers

What is a Library Sticker?

The library sticker is required for students to enter the library. To reduce long queues during the library sticker registration period, this system aims to organize and schedule students' registration appointments. This will help manage the registration process, minimize waiting times, and provide students with a more convenient and efficient way to register for their library stickers.

Note: The sticker is for CvSU Library use only.
